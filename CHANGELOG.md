# Изменения

## 0.1.0

- Сохранение выделенного кода в постоянную библиотеку.
- Встроенные и пользовательские категории; поиск по названию, категории и ключевым словам.
- Параметры `{{name}}` с подсказками и значениями по умолчанию.
- Редактирование кода через Ctrl+S, переименование, изменение метаданных и удаление с подтверждением.
- Импорт и экспорт JSON с проверкой формата, добавлением или полной заменой библиотеки.
- Четыре готовых алгоритма для импорта; автоматические проверки и инструкция на русском языке.
