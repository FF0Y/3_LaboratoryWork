# Проверка версии 0.1.0

Дата: 9 ноября 2026 года.

## Успешно

- `npm ci --ignore-scripts` — установлены зависимости из lock-файла.
- `npm run compile` — проверка типов TypeScript, ESLint и сборка esbuild.
- `npm run compile-tests` — скомпилированы тесты для Extension Development Host.
- `npm run test:unit` — 26 проверок, 26 успешных.
- Производственная сборка и упаковка через официальный `@vscode/vsce` — создан VSIX 0.1.0.

Проверены сохранение и повторное чтение библиотеки, последовательные и параллельные изменения, обработка ошибок записи, отмена диалогов, выбор категории, поиск по метаданным, буквальная подстановка параметров, переименование и удаление, сохранение кода через поставщик файлов, защита от устаревших правок, импорт/экспорт и неверные JSON-файлы. Четыре алгоритма из примеров импортированы, их параметры подставлены, полученный код выполнен на тестовых входах.

## Ограничение проверки

Интеграционный запуск `npm test` не дошёл до выполнения тестов в настоящем окне VS Code: Windows завершила тестовый редактор из-за ограничений доступа Electron к его каталогу (`install_dir_access.cc`). Это повторилось для установленного VS Code и отдельной скачанной копии. Настройки доступа к пользовательскому VS Code не менялись.

Командные тесты используют имитацию API и диалогов VS Code. Они не заменяют проверку настоящего интерфейса. В проект включены два интеграционных теста для регистрации команд и сохранения виртуального документа: запустите `npm test` в обычной локальной среде.

## Проверка вручную

1. Установить VSIX либо выполнить `npm ci`, затем F5 из проекта.
2. Импортировать `examples/algorithms.json` в режиме добавления.
3. Открыть TypeScript-файл; найти шаблон по словам «bfs», «Графы», «Стек».
4. Вставить стек с именем `NumberStack` и типом `number`; проверить замену всех меток и отмену Ctrl+Z.
5. Сохранить своё выделение в новую категорию, переименовать шаблон и изменить ключевые слова.
6. Через «Редактировать шаблон → Редактировать код» изменить код и нажать Ctrl+S. Снова вставить шаблон и проверить правки.
7. Экспортировать JSON, перезапустить VS Code и убедиться, что библиотека сохранилась.
8. Повторно импортировать JSON в режиме добавления: дубликаты должны быть пропущены.
9. Проверить отмену удаления и замены библиотеки, затем удаление с подтверждением.
