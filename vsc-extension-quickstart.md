# Быстрый запуск

1. Откройте папку с `package.json` в VS Code.
2. Выполните `npm ci`.
3. Нажмите F5, выбрав конфигурацию **Run Extension**.
4. В новом окне откройте файл и выполните через Ctrl+Shift+P команду **Шаблоны кода: Импортировать библиотеку**.
5. Выберите `examples/algorithms.json`, затем режим добавления.
6. Выполните **Шаблоны кода: Найти шаблон**, выберите алгоритм и задайте параметры.

Подробная инструкция — в README.md. Результаты проверок — в VALIDATION.md.
